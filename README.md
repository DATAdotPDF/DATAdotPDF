## Cybersecurity journey

Cybersecurity at Senac RJ is in progress in 2026. The 100-hour Cisco course prepares students for the Cisco Certified Support Technician Cybersecurity path.

Current course topics:

- Windows and Linux
- Networking fundamentals
- Common threats, attacks, and vulnerabilities
- Network, server, and application security controls
- Firewalls and security policies
- Cryptography
- Data confidentiality and availability
- Cisco Packet Tracer labs
- Attack and defense simulations

My broader learning roadmap adds:

- Systems and scripting: Linux, Windows, Bash, PowerShell, and Python
- Network analysis: TCP/IP, subnetting, DNS, TLS, Nmap, Wireshark, and tcpdump
- Defensive security: hardening, firewalls, IDS/IPS, EDR, SIEM, SOAR, logs, and incident response
- Application and cloud security: OWASP Top 10, IAM, AWS, Azure, and GCP security concepts
- Governance and risk: NIST, CIS Controls, vulnerability management, and security policies
- Practice: Cisco labs, CTFs, threat hunting, digital forensics, and blue-team exercises
